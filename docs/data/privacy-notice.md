## In short
- The game works fully **without** sharing any data.
- If you say **yes**, we save your answers and game choices for research.
- We **never** collect your name, address, IP address or exact location.
- You can **delete your data** any time from the menu.
- Data is stored in the **EU**.

## Legal basis
- **Your consent** (GDPR Art. 6(1)(a)).
- Say no → game still works, nothing is sent.
- Withdraw later → we stop collecting; you can also delete what we have.

## What we collect (only if you say yes)
| Data | Example |
|---|---|
| Age bracket | 25–34 |
| Gender | female / prefer not to say |
| Preparedness before + after playing | somewhat → fully |
| Household type (categories only) | has elderly: yes; apartment |
| Choices in the story | filled the bathtub |
| Scores + ending | water 2/2, ending "good" |
| Time spent per screen | 4 min on shop screen |
| Game language + device type | et, phone |
| Consent record | version, date, yes/no |

If you create an **optional account**:
- Your **email** — used only to log you in.
- Stored in the login system, **separate** from game data.
- Never shared with researchers.

## What we never collect
- Names — including the relative's name you type in the game
- Home address or exact location
- IP address in game data
- Full browser/device details (only "phone / tablet / desktop")

## On your device
The game saves some things in your browser, whether or not you consent:
- Game progress (to continue later)
- Notebook, sound + text speed settings
- Your last household setup (to pre-fill the next game)
- Whether you've answered the start survey (so we ask only once)

These stay on your device. Clear your browser data to remove them.

## Your rights
You can:
- **See** your data
- **Correct** it
- **Delete** it — "Delete my data" in the menu
- **Take** a copy
- **Withdraw consent** — any time, no reason needed
- **Complain** to the Estonian Data Protection Inspectorate (Andmekaitse Inspektsioon) — [www.aki.ee](https://www.aki.ee)

Guests: deleting data from a browser works only on that same browser.

Contact for any of these: `[[TBD — research contact email]]`

## Security
- Encrypted connections (HTTPS).
- Database rules: each player can reach only their own rows.
- Master keys never in game code.
- Access limited to named people with 2FA.

## Changes to this notice
- Every change gets a new version number.
- Big changes → we ask for your consent again.
